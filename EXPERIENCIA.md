# EXPERIENCIA.md

## 🛠️ Proceso Realizado

Durante el desarrollo del repositorio RA-Tech, se realizaron las siguientes actividades:
- Configuración del repositorio local y remoto en GitHub.
- Creación y gestión de ramas para mantener una estructura ordenada de trabajo.
- Uso de `git add`, `git commit` y `git push` para el control de versiones.
- Simulación de un Issue para reportar un error con etiquetas y milestones.
- Redacción de archivos de documentación como este para registrar la experiencia del proyecto.

## 📚 Aprendizajes Obtenidos

- Aprendí a usar Git y GitHub de forma más estructurada, incluyendo la gestión de ramas y Issues.
- Comprendí la importancia de documentar el trabajo realizado para mantener una trazabilidad clara del proyecto.
- Mejoré mis habilidades en la resolución de errores relacionados con Git y rutas de archivos.

## ⚠️ Dificultades Encontradas

- Inicialmente, hubo errores al intentar hacer push porque el repositorio remoto no existía o estaba mal configurado.
- También tuve problemas al agregar archivos que no estaban en el directorio actual, lo que me llevó a verificar cuidadosamente las rutas.
- Aprendí a solucionar estos errores revisando el estado del repositorio y utilizando comandos como `git remote -v` y `ls`.
